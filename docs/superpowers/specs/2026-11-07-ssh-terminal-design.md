# SSH в терминале: сессии, вкладки, проводник SFTP

Дата: 2026-11-07. Основание для блока оболочки с `ssh=` (документ автоматизации, этап 1).

## Зачем

Замена MobaXterm внутри Qvarch: сохранённые сессии, терминал на сервере, проводник файлов сервера рядом с терминалом, обмен файлами между ПК и сервером. Тот же слой сессий потом даёт блокноту команды на сервере с отдельными stdout, stderr и кодом выхода.

## Решения пользователя

- Вход по паролю, пароль сохраняется в сессии.
- Импорт из MobaXterm не нужен.
- Проводник, сохранение сессий и обмен файлами — обязательны.

## Устройство

**Сессии** (`shared/ssh/sessions.ts` — модель и проверка; `main/ssh/sessionStore.ts` — хранение).
- Сессия: id, имя, папка (путь вида `Работа/Серверы`), хост, порт, пользователь, начальная папка проводника.
- Хранятся в `data/ssh-sessions.json`. Пароль — в том же файле, зашифрован `safeStorage` (DPAPI). В окно пароль не уходит никогда: окно знает только «пароль сохранён».
- Дерево папок строит чистая функция (с тестами).

**Соединения** (`main/ssh/sshConnections.ts`).
- Одно соединение `ssh2` на сессию, по нему каналы: shell — на каждую вкладку, SFTP — для проводника, отдельный SFTP на каждую передачу.
- Вход: пароль и keyboard-interactive (сервер спрашивает пароль вопросом — отвечаем сохранённым паролем). Нет пароля или он не подошёл — окно спрашивает пароль; галочка «сохранить».
- `keepaliveInterval` 20 с, `readyTimeout` 20 с.
- Разрыв: вкладка пишет «соединение потеряно», «Перезапустить» подключается заново. Проводник при следующем действии подключается сам.
- Последний канал закрыт — соединение закрывается.

**Ключ сервера** (`shared/ssh/knownHosts.ts` — разбор и запись строк; `main/ssh/hostKeys.ts`).
- Проверка по настоящему `~/.ssh/known_hosts`, включая форму `[host]:port` и хешированные строки `|1|`.
- Незнакомый сервер — нативный диалог с отпечатком `SHA256:…`: «Доверять и запомнить» / «Только сейчас» / «Отмена».
- Ключ изменился — громкое предупреждение, по умолчанию «Отмена».

**Вкладка SSH в терминале.**
- Класс терминала получает общий интерфейс процесса (запись, размер, остановка, данные, выход): локальный PowerShell или канал shell по SSH. Вкладки, панели, буфер перерисовки, пресеты и реакции общие.
- Разметка оболочки (папка, код выхода, «занят») — только у локального PowerShell. У SSH-вкладки реакции читают весь вывод.

**Проводник SFTP** (`main/ssh/sftpService.ts`, `shared/ssh/remotePath.ts`).
- Панель справа от терминала, когда открыта SSH-вкладка (сворачивается).
- Путь крошками, «вверх», «обновить», «домой», список: имя, размер, дата, права.
- Двойной клик по папке — войти.
- Создать папку, переименовать, удалить (папку — рекурсивно, с подтверждением).
- Загрузка: перетащить файлы и папки из Проводника Windows на список или кнопкой «Загрузить».
- Скачивание: «Скачать» (в «Загрузки»), «Скачать в…» (выбор папки), «Открыть» (скачать во временную папку и открыть программой Windows).
- Перетаскивание из проводника в Проводник Windows — позже (Electron требует готовый файл на диске в момент начала перетаскивания).

**Передачи** (`shared/ssh/transfers.ts` — очередь, чистая; `main/ssh/transferQueue.ts`).
- Очередь: по 3 файла одновременно, прогресс, скорость, отмена, ошибка по файлу не останавливает остальные.
- Папки разворачиваются в файлы.
- Запись во временное `имя.part`, переименование в конце — оборванная передача не оставляет полуфайл под настоящим именем.
- Список передач — внизу панели проводника.

## Пограничные случаи

- Сервер на Windows (OpenSSH): пути вида `/C:/Users` — крошки и «вверх» работают.
- Имена файлов с пробелами, кириллицей, без расширения; скрытые файлы (точка) — показываются.
- Символьные ссылки: показываются как ссылки, ведущие на папку — открываются как папки.
- Папка без прав на чтение — понятная ошибка в панели, а не падение.
- Огромная папка (10 000+ файлов) — список виртуализировать не нужно сразу, но сортировка и показ не должны вешать окно (обрезать показ, сообщить).
- Вкладку SSH закрыли во время передачи — передачи идут: соединение живёт, пока жив хоть один канал.
- Пароль поменялся на сервере — вход падает, окно спрашивает новый.
- Сессию удалили, а вкладка открыта — вкладка работает до закрытия.
- Приложение закрывается — каналы и соединения закрываются, передачи обрываются (остаются `.part`).

## Вне первой поставки

- Вход по ключу и через агент, промежуточный сервер.
- Правка удалённого файла с обратной заливкой.
- Следование проводника за папкой терминала.
- Передача папок архивом tar.
- Команды по SSH для блокнота (`exec`) — в этапе блока оболочки.
