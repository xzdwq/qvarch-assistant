# Qvarch Assistant

Десктоп-трекер рабочего времени (Windows). Время пишется автоматически всегда, пока ПК включён; вы потом
размечаете непрерывную шкалу — что делали, когда, параллельно с чем. Всё хранится только локально, без интеграций.

## Возможности

- **Непрерывная шкала.** Отрезок начинается при запуске/выходе из сна и закрывается при сне/выключении; heartbeat раз
  в 15 с. Перезапуск приложения без перезагрузки ПК (до 15 мин) не считается выключением.
- **Island** — плашка поверх всех окон с двумя мини-дорожками. Перетаскивается за иконку перемещения или шапку,
  по наведению разворачивается: шкала, разметка, список записей и приложений. `Ctrl+Alt+Space` — вызвать.
- **Разметка.** Клик ставит отметку времени (её плашку можно тянуть — выделение), протягивание выделяет отрезок,
  правый клик — вид занятости, объединение, удаление. Блоки тянутся целиком и за края; пересечения уходят на
  параллельные дорожки (видно до 3, ниже всегда есть пустая). Ctrl+клик — несколько блоков.
- **Виды занятости** настраиваются (название, цвет, иконка).
- **Активность.** Фоновый PowerShell-сэмплер (WinAPI) раз в 2 с снимает только активное приложение и кто держит
  микрофон. Заголовки окон не читаются и не хранятся. Простой — по отсутствию ввода.
- **Созвоны** — локально, по приложению, держащему микрофон (Teams, Zoom, Telegram…).
- **Календарь истории** по дням и **журнал** событий дня (с экспортом CSV).

## Разработка

Нужен Node 20+ (в репозитории `.node-version` = 22.20.0).

```bash
npm install
npm run dev        # electron-vite dev с hot reload
npm test           # vitest — доменная логика
npm run typecheck
npm run dist       # установщик NSIS + portable в dist/
```

> Если запускаете из терминала VS Code и Electron стартует как Node (`app` is undefined), сбросьте
> `ELECTRON_RUN_AS_NODE` (VS Code выставляет его своим дочерним процессам).

## Данные

`%APPDATA%\Qvarch Assistant\data\`:
- `days/YYYY-MM-DD.json` — отрезки ПК, активность приложений, созвоны, записи;
- `settings.json` — настройки.

## Структура

```
src/shared    доменная логика без Electron (шкала, дорожки, классификация приложений) + типы/IPC-контракт
src/main      трекер, сэмплер, хранилище, окна, трей
src/preload   мост window.qa
src/renderer  island.html (плашка) и index.html (главное окно), Vue 3
resources     winprobe.ps1 — системный сэмплер
tests         vitest
```
